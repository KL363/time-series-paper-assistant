# lingerskill 提示词库

选择符合当前问题的一条即可。新会话或换论文时明确使用 `lingerskill`；如果客户端未发现自然语言调用，先用 `$lingerskill` 或技能选择器选择。“继续追问”适用于已启用的同一篇论文。默认每轮只深入一个阶段或核心模块，先短导读；普通“完整讲解”仍分轮，明确要求一次性完整分析则可例外。

每个新阶段按**研究动机 → 计算原理 → 数学公式 → Tensor Shape → 代码实现**展开，附原文定位，以关键结论和待解决问题收尾后停止。无适用公式、形状或代码时简述原因，不编造；无待解决问题时说明“当前无”。单点追问只解答当前疑点，等待明确继续才推进，不自动进入下一阶段。

## 最短调用

```text
使用lingerskill给我讲解这篇论文。
```

## 架构与数据流精读

```text
使用lingerskill给我讲解这篇论文。
先给出整体架构，再沿数据流讲原始数据、预处理、batch、核心模块、预测与训练。
每轮只深入一个阶段或核心模块，按研究动机、计算原理、数学公式、Tensor Shape、代码实现的顺序解释。
区分复用、组合、改造与新机制，每轮以关键结论和待解决问题收尾后停止。
关键解释附原文章节、图、公式或页码，最后指出最值得回读的几处原文。
有官方代码就结合代码讲，没有可访问的代码就用教学伪代码。先给短导读，等我说“继续”再逐段展开。
```

## 数据处理与训练

```text
使用lingerskill给我讲解这篇论文，只关注数据处理与训练。
以一批数据为例，追踪数据读取、预处理、窗口或分块、模型输入、预测、loss 和参数更新。
如存在归一化、频域处理或反归一化，说明操作轴、统计量来源和形状变化。
区分训练与推理，未说明的配置标为未知；分轮用原文和代码或教学伪代码串起全过程，本轮先讲数据准备。
```

## 结合官方代码

```text
使用lingerskill给我讲解这篇论文及其官方代码：[论文和仓库链接]。
顺着数据加载、预处理、forward、子模块、预测头、loss、参数更新和推理入口讲解。
将代码位置与论文公式、图示连接起来，解释张量的含义和变化。
以静态阅读理解作者思路为主；影响理解的差异简要说明。
无法访问或缺失的路径用教学伪代码解释，并说明依据。
```

## 没有代码

```text
使用lingerskill给我讲解这篇论文，目前没有可访问的官方代码。
根据论文分轮写教学伪代码，逐步覆盖预处理、forward、loss、训练循环与预测。本轮只展开一个完整的小环节。
注释对应原文位置，区分论文明确步骤、解释性示意和未知细节。
用小张量说明核心模块如何改变数据，不把示例维度当成论文配置。
```

## 模块来源与贡献

```text
使用lingerskill给我讲解这篇论文，重点解释各模块的功能与来源。
区分直接复用、组合、改造、新机制和数据或训练贡献，说明作者具体改了什么。
先看本文方法与引用，再按需核对相关前作，给出原文定位。
将作者声明与已核对的来源证据分开，缺少材料时保留不确定性。
```

## 阅读节奏

- “继续”：从下一处未讲内容接着讲。
- “继续解释当前公式”：只解答当前疑点，不进入下一阶段。
- “跳过”：进入下一主题，不自动回补。
- “跳到训练”：直接调整路线。
- “每次不超过 500 字”：进一步缩短输出。
- “谢谢”“明白了”：确认收到，不触发推进。
- “一次性完整分析”“一条消息讲完整篇”“不分阶段”：本次指定范围内取消阶段等待和默认篇幅预算，完整回答；仍遵守明确指定的长度。

## 明确要求一次性完整分析

```text
使用lingerskill给我一次性完整分析这篇论文，不分阶段等待。
覆盖模型架构、数据管线、核心模块、训练与预测，以及模块来源。
保留研究动机、原理、公式、Tensor Shape 和官方代码或教学伪代码，并附原文定位。
```

此请求不会被强制压缩为精简版；普通后续追问恢复默认分阶段规则。若只想完整分析某个模块，可直接限定范围。

## 同一篇论文的继续追问

- **模块：**“只深入 `<模块>`，按动机→原理→公式→Tensor Shape→代码解释，把关键步骤定位到原文。”
- **数据：**“从一个 batch 出发，解释归一化、reshape、频域处理的操作轴和含义。”
- **训练：**“用伪代码串起 forward、loss、反向传播和参数更新，标出未知配置。”
- **代码：**“把 `<公式>` 对应到官方代码的文件和函数，说明为什么这样计算。”
- **来源：**“只比较本文 `<模块>` 与引用的 `<前作>`，具体说明继承与改变了什么。”
- **回读：**“列出最值得回读的三处原文，每处给位置和要理解的问题。”

## 明确请求的可选扩展

**阶段 06，实验与消融：**

```text
使用lingerskill阅读这篇论文，并额外检查实验与消融是否支持作者结论。
重点讨论：[具体问题]。将已有结果与建议补充的实验分开。
```

**阶段 07，研究改进：**

```text
使用lingerskill阅读这篇论文，并为 [任务/领域] 提出最多三个可检验的改进想法。
说明修改位置、动机、前作关系，以及什么结果会支持或否定这个想法。
```

**阶段 08，导出：**

```text
将这次 lingerskill 讲解导出为一个 Markdown 文件。
包含架构、数据流、核心模块、训练伪代码和原文定位，保留未确认事项。
不额外创建状态文件或拆分成多份卡片。
```

单纯要求“总结”“整理”仍在聊天中回答，明确要求导出或保存时才创建文件。
